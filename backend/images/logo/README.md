# Logo de Boutique Ana

Coloca aquí el archivo de logo de la página.

## Nombre del archivo

El logo debe llamarse `logo.png` o `logo.jpg` para que se cargue automáticamente.

## Ubicación

- Archivo: `backend/images/logo/logo.png` o `backend/images/logo/logo.jpg`
- URL: `http://localhost:3000/images/logo/logo.png`

## Formatos soportados

- PNG (recomendado para logos con transparencia)
- JPG/JPEG
- SVG (si se usa, cambiar la extensión en el código)

## Tamaño recomendado

- Ancho: 60-120px
- Alto: 60-120px
- Formato: Cuadrado o rectangular vertical
- Resolución: 2x para pantallas Retina (120x120px para un logo de 60x60px)
